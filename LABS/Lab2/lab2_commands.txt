Lab 2 — command sequence (Windows PowerShell, repo root)

Production branch (prod):
  git switch prod
  docker compose up -d --build
  docker compose ps
  docker compose logs -f --tail=100 web
  docker compose logs -f --tail=100 db
  docker compose down

Dev branch (dev) — Postgres + reload + bind mount:
  git switch dev
  docker compose -f docker-compose.yml -f docker-compose.dev.yml up -d --build
  docker compose -f docker-compose.yml -f docker-compose.dev.yml ps
  docker compose -f docker-compose.yml -f docker-compose.dev.yml exec web poetry show
  docker compose -f docker-compose.yml -f docker-compose.dev.yml down

App in browser:
  Open http://localhost:8000/docs (site must not use http://0.0.0.0:8000 in the browser)
